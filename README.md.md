# depviz — визуализация графа зависимостей (этап 1)

Практическая работа №2, Вариант №6, этап 1.

## Общее описание

CLI-приложение на Python, которое принимает параметры анализа
зависимостей пакетов и печатает их в формате ключ-значение.
Этап 1 реализует только конфигурацию и валидацию; сбор данных,
обход графа и визуализация — в следующих этапах.

## Параметры

| Параметр        | Тип      | Назначение                                  |
|-----------------|----------|---------------------------------------------|
| `--package`     | str      | Имя анализируемого пакета                   |
| `--repo`        | str      | URL репозитория или путь к файлу            |
| `--test-mode`   | flag     | Работа с тестовым репозиторием (файл)       |
| `--version`     | str      | Версия пакета                               |
| `--ascii-tree`  | flag     | Вывод зависимостей ASCII-деревом            |
| `--max-depth`   | int      | Максимальная глубина анализа (1..100)       |
| `--filter`      | str      | Подстрока для фильтрации пакетов            |

## Сборка и запуск

```bash
python -m venv .venv && source .venv/bin/activate
make install
make run ARGS="--package requests --repo https://pypi.org --version 2.31.0 --max-depth 3"
